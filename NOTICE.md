# Provenance

Eternal Watch is an Android adaptation of EL-Klock clock/alarm behavior.
`GameSnapshot`, `AlarmEngine` and `SpecialDays` adapt GPL-3.0-only logic/catalog
from `Agundur-KDE/EL-Klock`, commit `e5a2bead1d8076e157ff7769b464d2c363afd0fc`,
specifically `ElData.js` and `Days.js`. Adaptation and Android code: Agundur, 2026.
See LICENSE for GPL version 3. Repository visibility remains private.

English game names originate from the Eternal Lands Wiki Special_Days list;
clock rules use six game hours/day and 61 real seconds/game minute.
Public live data is provided by Mercator at
https://mercator.holy-eternalland.de/botmanagement/elinfo.json .
Eternal Watch is an unofficial companion, not an official Eternal Lands product.

No EL-Klock template code or unverified invasion-horn audio is included.
Android system notification sounds are used instead.
